## Вилки настольного тенниса (DEMO)

При запуске стратегия один раз сканирует доступные матчи со счётом 0:0 и затем
обрабатывает полученную очередь последовательно. После выбора матча бот не
переключается на другой: он остаётся на текущем событии и ждёт появления вкладки
«2-я Партия», если она ещё не отрисована сайтом.

В выбранной второй партии читается только точный рынок «1X2. 2-я Партия».
Первое виртуальное плечо ставится сразу на исход с меньшим коэффициентом; при
полном равенстве используется стабильный tie-break П1. После этого принятое
значение первого коэффициента фиксируется, а бот следит только за коэффициентом
противоположного игрока.

Нулевая граница второго плеча рассчитывается математически, а минимальный запас
вилки задаётся переменной окружения `TABLE_TENNIS_MIN_ARB_PERCENT` (по умолчанию
`0.5`). Частота чтения DOM задаётся `TABLE_TENNIS_ODDS_POLL_INTERVAL`.

Когда второе плечо достигает допустимой вилки, обе DEMO-ставки фиксируются,
история и процент арбитража сохраняются, резерв освобождается по гарантированной
(минимальной из двух исходов) прибыли, после чего бот сразу открывает следующий
матч из уже отсканированной очереди. Повторного сканирования каталога между
матчами нет. Реальные кнопки коэффициентов букмекерского сайта не нажимаются.

## Canvas OCR

Основной движок — singleton `RapidOCR` (ONNX Runtime), fallback —
`pytesseract`. Tesseract ищется через `TESSERACT_CMD`, `PATH` и стандартные
Windows-каталоги. Отсутствие Tesseract не мешает работе RapidOCR.

Persistent Chromium создаётся единственным `BrowserManager` при старте
FastAPI. `POST /api/demo/stop` останавливает только worker; закрыть browser
можно через `POST /api/browser/stop` или штатным завершением backend.

Управление браузером:

```http
GET  http://127.0.0.1:8000/api/browser/state
POST http://127.0.0.1:8000/api/browser/start
POST http://127.0.0.1:8000/api/browser/stop
```

Диагностика текущего canvas:

```http
POST http://127.0.0.1:8000/api/browser/market-canvas-debug
```

Снимки сохраняются в `backend/diagnostics/canvas/`. Используется только
`canvas.market-grid-canvas__canvas`, полный screenshot браузера не создаётся.
